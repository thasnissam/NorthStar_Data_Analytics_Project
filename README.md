# NorthStar Data Analytics Project

This repository contains the implementation of a Databases and Analytics coursework project based on the NorthStar Urban Mobility and Logistics case study.

The project combines:
- SQL within R
- R analytics and visualisation
- Python data processing
- MongoDB Atlas (NoSQL)
- Query optimisation and indexing

The analysis focuses on identifying operational inefficiencies, delivery failures, customer dissatisfaction, and cost variations across logistics operations.

## Repository Structure
- `Data/` → Operational datasets
- `Notebooks/` → Google Colab notebooks for analytics and database implementation
- `Documentation/` → Supporting project documentation

## Technologies Used
- Python
- R
- MongoDB Atlas
- Pandas
- NumPy
- ggplot2
- PyMongo
