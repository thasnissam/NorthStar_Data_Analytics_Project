# NorthStar Operational Datasets

This folder contains all datasets used for the Databases and Analytics coursework project based on the NorthStar Urban Mobility and Logistics case study.

The datasets simulate operational, financial, behavioural, and customer-service activities across a large-scale urban mobility and logistics organisation.

---

# Dataset Overview

## 1. customers.csv
Contains customer demographic and engagement information.

### Example Attributes
- customer_id
- customer_name
- communication_preference
- customer_segment
- account_status

### Analytical Purpose
Used for:
- customer segmentation
- satisfaction analysis
- behavioural analytics

---

## 2. orders.csv

### Analytical Purpose
