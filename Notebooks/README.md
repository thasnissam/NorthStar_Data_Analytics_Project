
# NorthStar Analytics Notebooks

This folder contains all Google Colab notebooks used for the Databases and Analytics coursework project based on the NorthStar Urban Mobility and Logistics case study.

## Purpose
The notebooks demonstrate:
- SQL operations within R
- Statistical analysis and visualisation in R
- Python-based data processing and analytics
- MongoDB Atlas database implementation
- Query optimisation and indexing strategies

The analysis focuses on identifying:
- Operational inefficiencies
- Delivery failures and delays
- Customer dissatisfaction trends
- Cost escalation across hubs and routes
- Behavioural and operational risk patterns
